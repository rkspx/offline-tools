# File Converter

Converts still images, creates PDFs from images, merges/splits PDFs, and decodes browser-supported audio to 16-bit PCM WAV. Batch output can be downloaded as a ZIP.

It does not convert office documents or video. Animated images are flattened, JPEG transparency becomes white, audio output is uncompressed WAV, and input decoding support varies by browser. Files are limited to 150 MB.
