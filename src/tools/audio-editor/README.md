# Audio Editor

Decodes local audio with browser APIs and performs trimming, fades, gain, peak normalization, mono conversion, a simple noise gate, and high-pass filtering. Output is 16-bit PCM WAV.

Files are limited to 500 MB and 30 minutes. It is not a multitrack or nondestructive editor, compressed export is unavailable, effects are intentionally basic, and input codec support depends on the browser and OS.
