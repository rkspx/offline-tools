# Compliance Gatekeeper

Performs local static inspection of EML, DOCX, and PDF content for links, attachment metadata, classification terms, and active-content indicators, then exports JSON/HTML reports.

It does not render or execute attachments, verify sender identity, detonate active content, or prove that a document is safe or policy-compliant. Text extraction and pattern matching can miss obfuscated, image-only, encrypted, or unsupported content; human review remains required.
